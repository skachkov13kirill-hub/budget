# ДАШБОРД — Система учёта DressCode (бывш. БЮДЖЕТ)

## Что это
Финансовая экосистема для сети из 10 ателье DressCode. После FIX-031 (11.05.2026) состоит из 4 компонентов:
1. **report.html** — мобильная форма для ежедневных отчётов (ОСНОВНОЙ инструмент сбора данных)
2. **index.html** — PWA-дашборд с 4 вкладками (🏢 Бизнес / 📅 Дни / 💳 Оплаты / 🏠 Недвига). Оплаты и Недвига кликабельны и общим state с `@atelie_finance_bot`
3. **state_api на VPS (`nedviga_api.py`)** — единый бэкенд для бота и дашборда. GET `/api/nedviga/snapshot`, GET `/api/atelie/snapshot`, POST `/api/nedviga/mark`, POST `/api/atelie/mark`, POST `/api/atelie/branch_report`. На VPS:8765, наружу через nginx `/dresscode-api/`.
4. **Google Apps Script v47** — API для отчётов филиалов (`getDailyChart`, `writeBranchDaily`, `getAll` и др.)

`bot_v9` — на паузе (Telegram-блокировки в РФ). `nightly_audit` отключён в `main.py:119` намеренно по FIX-031.

## Как работает
```
Филиалы → report.html (форма) → Apps Script API → Google Sheets "АТЕЛЬЕ 2026"
                                                           ↓
Кирилл ← index.html (дашборд) ← Apps Script API ←────────┘
```

## Apps Script API (ключевые endpoints)

|--------|-----------|
| getAll | Всё разом: филиалы + кредиты + балансы + настройки |

| getBalances | Балансы счетов |
| getPaymentsStatus | Статус оплат (аренда/кредиты) |
| getTasks | Задачи |
