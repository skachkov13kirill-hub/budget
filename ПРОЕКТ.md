# ДАШБОРД — Система учёта DressCode (бывш. БЮДЖЕТ)

## Что это
Финансовая экосистема для сети из 10 ателье DressCode. Состоит из 4 компонентов:
1. **report.html** — мобильная форма для ежедневных отчётов (ОСНОВНОЙ инструмент сбора данных, заменил бот)
2. **index.html** — PWA-дашборд с аналитикой (используется Кириллом ежедневно)
3. **Telegram Bot v9** — на паузе, Telegram глушат в РФ. Отвечает на запросы (баланс, кредиты, арендa)
4. **Google Apps Script v47** — единое API для всех фронтендов

## Как работает
```
Филиалы → report.html (форма) → Apps Script API → Google Sheets "АТЕЛЬЕ 2026"
                                                           ↓
Кирилл ← index.html (дашборд) ← Apps Script API ←────────┘
```

## Apps Script API (ключевые endpoints)
| Action | Что делает |
|--------|-----------|
| getAll | Всё разом: филиалы + кредиты + балансы + настройки |
| getBranches | Данные филиалов за месяц/год |
| writeBranchDaily | Записать дневной отчёт (от report.html) |
| getCredits | Список кредитов |
| getBalances | Балансы счетов |
| getPaymentsStatus | Статус оплат (аренда/кредиты) |
| getTasks | Задачи |

## Что работает ✅
- report.html собирает данные от 10 филиалов
- Dashboard показывает план/факт по каждому филиалу
- Вкладки: Бизнес, Daily (14-дневный график), Платежи, Задачи, Агенты
- PWA (оффлайн режим, кэш)
- Семейный бюджет (js/family.js + js/family-features.js, отдельный Sheets)
