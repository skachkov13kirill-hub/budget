   - Менделеева 16 (8 лет) сейчас хуже Воронцовского 8 (4 года)
   - Возраст не гарантирует стабильность

2. **Быстрый старт ≠ долгий успех**
   - Петровский 14: +143% за год, но уже падает на 4-й год
   - Воронцовский 8: +50% за год, продолжает расти на 4-й год

3. **Премиализация требует запаса**
   - Работает только при потере <15% клиентов
   - Рост чека должен быть >40% для компенсации

4. **Ранняя реакция критична**
   - Менделеева игнорировала -7% в 2023 → сейчас -39%
   - Петровский игнорирует -7.7% в 2025 → ???

5. **Учитесь у успешных**
   - Воронцовский 8 = эталон правильного роста
