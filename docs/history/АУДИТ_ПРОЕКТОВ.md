## КРИТИЧЕСКИЕ ПРОБЛЕМЫ (СРОЧНО)

### 1. УТЕЧКА СЕКРЕТОВ — claude_key, github_token, service_account

| Файл | Размер | Угроза |
|------|--------|--------|
| `PAKET_1_KOMPYUTER/claude_key` | 399 байт | API-ключ Claude (Anthropic) — полный доступ к аккаунту |
| `PAKET_1_KOMPYUTER/github_token.txt` | 41 байт | GitHub-токен — доступ к репозиториям |
| `PAKET_1_KOMPYUTER/bot_v9/service_account.json` | ~2 КБ | Google Service Account — доступ к Google Sheets |
| `PAKET_1_KOMPYUTER/bot_v9/config.py` | ~1.5 КБ | Вероятно содержит Telegram Bot Token и другие ключи |

**ЧТО ДЕЛАТЬ НЕМЕДЛЕННО:**
1. Отозвать (revoke) Claude API ключ в console.anthropic.com
2. Отозвать GitHub токен в github.com → Settings → Developer settings → Personal access tokens
3. Отозвать/перевыпустить Google Service Account ключ в Google Cloud Console
4. Проверить config.py — если там Telegram Bot Token, перевыпустить через @BotFather
5. После перевыпуска — НЕ хранить ключи в файлах! Использовать переменные окружения (.env файл + .gitignore)
6. Удалить файлы claude_key и github_token.txt из репозитория

## СВОДКА РИСКОВ

| Риск | Уровень | Статус |
|------|---------|--------|
| Утечка API-ключей | КРИТИЧЕСКИЙ | Нужно отозвать немедленно |
| Смешение проектов | ВЫСОКИЙ | Нужна реструктуризация |

| Мусорные файлы | НИЗКИЙ | Занимают место, создают шум |
| __pycache__ в репо | НИЗКИЙ | Не должны быть в git |

## ПРИМЕЧАНИЕ

Большинство файлов на данный момент заблокированы файловой системой (Resource deadlock — вероятно, virtiofs). Содержимое config.py, main.py и service_account.json не удалось прочитать, но по названиям файлов и контексту проекта — там гарантированно есть секреты (Telegram token, Google credentials).

Прежде чем перемещать файлы — убедись, что у тебя есть бэкап всей папки!
