### Модуль 2: ФИНАНСЫ — ДДС (нового нет ничего)
**ДДС = Движение Денежных Средств** — каждый день видно: сколько пришло, ушло, остаток.

**Ввод данных (голос/текст):**
```
«Получил 100 000 от Богатырёва»         → приход +100К, источник: кредит
«Заплатил 27 000 аренда М16»            → расход -27К, категория: аренда
«Эквайринг пришло 38 500»               → приход +38.5К, источник: бизнес
«Снял с расчётного 50К»                 → перемещение РСч→наличка
```

**Автоматически** получать из банка (в будущем через выписки) или вручную.

**Отчёты:**
```
Сегодня (24 фев):
  Пришло:  38 500₽  (эквайринг)
  Ушло:   -27 000₽  (аренда М16)
  Баланс: +11 500₽

На счетах: РСч 483К | Наличка ~150К | Итого 633К
```

**Хранение:** новый лист «ДДС 2026» в таблице АТЕЛЬЕ 2026.

## ГОЛОСОВОЙ ВВОД — КАК ЭТО РАБОТАЕТ

```
Ты говоришь: «Поставь встречу завтра с трёх до четырёх с Кириллом»

1. Telegram → bot.py получает .ogg файл
2. bot.py → Whisper API → «Поставь встречу завтра с трёх до четырёх с Кириллом»
3. bot.py → Claude API (Haiku) → JSON:
   {
     "module": "calendar",
     "action": "create_event",
     "title": "Встреча с Кириллом",
     "date": "tomorrow",
     "time_start": "15:00",
     "time_end": "16:00"
   }
4. bot.py → Google Calendar API → создаёт событие
5. bot.py → Telegram: «✅ Создал: Встреча с Кириллом, 25 февраля 15:00–16:00»
```

**Стоимость одного голосового запроса (~30 сек):**
- Whisper: $0.003 (полкопейки)
- Claude Haiku: $0.001
- Итого: **меньше 1 рубля за запрос**
