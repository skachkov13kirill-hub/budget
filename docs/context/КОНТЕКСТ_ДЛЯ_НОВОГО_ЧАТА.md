## Что это

Телеграм-бот для управления сетью из 10 ателье (DRESSCODE). Основная задача: портные в групповых чатах пишут `20000 1` (оборот и клиенты) → бот автоматически записывает в Google Sheets. Также бот умеет: финансовый анализ, управление задачами, голосовые сообщения (Whisper), ИИ-роутинг (Claude Haiku), парсинг PDF-выписок Сбербанка.

---

## Архитектура (актуальная)

```
Портной в Telegram → Бот (Python, VPS) → gspread → Google Sheets
```

Apps Script **убран из записи дневных оборотов** — теперь это делает gspread (sheets_direct.py) напрямую. Apps Script **остаётся** для: Calendar events, bizrules, qrmerchants, transactions, addTask.

## Известные нюансы

- **Даты в таблице:** бот пишет в формате `YYYY-MM-DD`. Старые строки могут быть в `DD.MM.YY` — `_normalize_date()` в `sheets_direct.py` обрабатывает оба формата
- **Apps Script:** URL остаётся в config.py и используется для нескольких функций. Не удалять
- **Пароли от VPS:** скрипт деплоя спрашивает пароль ~10 раз (на каждый scp/ssh). Можно настроить SSH-ключи чтобы не вводить
- **pip на VPS:** всегда с флагом `--break-system-packages` (нет venv)
- **Портные в чатах:** могут записать любые цифры, владелец получает уведомление о каждой записи
