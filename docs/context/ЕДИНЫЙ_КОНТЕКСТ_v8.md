### Whisper API не работает с российского VPS
OpenAI блокирует запросы с IP 176.124.208.212 (Россия): `403 unsupported_country_region_territory`.
Варианты решения: прокси для OpenAI, Google Speech-to-Text, локальный faster-whisper.

В config.py стоит `YOUR_ANTHROPIC_KEY`. Без него ИИ-роутинг работает на regex-fallback (не на Claude Haiku). Получить ключ: console.anthropic.com → API Keys.
