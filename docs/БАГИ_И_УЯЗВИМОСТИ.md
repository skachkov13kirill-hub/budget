### Н1 (НОВЫЙ): Г11 — API возвращает нули на дашборде
**Обнаружено в сессии 8.**
**Что:** На дашборде Графская 11 показывает Ателье: 0Р, План: 0Р (0%).
**Факты:**
- В Google Sheets лист Г11 содержит данные за февраль: 15 900 + 4 600 + 1 600 = 22 100Р (3 дня)
- В PLAN_2026 для Г11 месяцы 1-2 имеют {a:0, h:0, c:0}, данные начинаются с месяца 3
- Январь полностью пустой — филиал начал отчитываться только в конце февраля
**Вероятная причина:** API getBranches() может не находить данные для Г11 или функция суммирования не охватывает нужные строки. Нужно отладить handleGetBranches() в Apps Script для листа Г11.
